# Prefunded Quote (Internal Wallet)

A prefunded quote extends the standard [quote](/api-reference/endpoint/quote/get-quote) flow: instead of sending funds to a bank account or paying a Lightning invoice, the source amount is deducted directly from your internal wallet.

## Create Quote

`POST {{url}}/quote`

```json
{
    "amount": "1000",
    "sourceCurrency": "USDTCENT",
    "targetCurrency": "NGNKOBO",
    "paymentMethod": "ONCHAIN",
    "paymentCurrency": "USDTCENT",
    "sourceWallet": "USDT",
    "autopayout": true,
    "beneficiary": {
        "bankAccountNumber": "7012345678",
        "bankAccountName": "Example Customer",
        "bankCode": "100004",
        "bankName": "OPAY"
    }
}
```

## Accept Quote (Pay with Internal Wallet)

To pay with your internal wallet, call the accept endpoint with the quote `id` in the path.

`POST {{url}}/wallet/payout/:id/accept`

```json
{
    "sourceWallet": "USDT"
}
```

**200 Response:**

```json
{
    "status": "ok",
    "message": "quote is being processed"
}
```

**400 Response:**

```json
{
  "status": "error",
  "message": "Error processing internal transfer: Insufficient balance in USDT wallet"
}
```
